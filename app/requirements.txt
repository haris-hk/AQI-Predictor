# Streamlit Community Cloud dependency file.
#
# It MUST live here (next to the entrypoint) and it MUST be called
# requirements.txt. Community Cloud only recognises uv.lock, Pipfile,
# environment.yml, requirements.txt and pyproject.toml, searching the
# entrypoint's directory first and then the repository root. A custom name
# such as requirements-app.txt is never read, and the root requirements.txt
# carries no plotly, so the app would crash on import.
#
# Deliberately lean. The dashboard renders precomputed Parquet and JSON: it
# never unpickles a model, so scikit-learn, statsmodels, shap and torch are
# not needed here. Keeping them out is what holds the app inside a Community
# Cloud memory allowance.
streamlit>=1.49
plotly>=5.20
pandas>=2.1,<3.1
numpy>=1.26,<3
pyarrow>=15
requests>=2.31
